## Source and CI gates

[GitHub Actions run `33045870310`](https://github.com/pvd232/viper/actions/runs/33045870310)
passed for the release commit. The run covered Python 3.11, 3.12, 3.13, and
3.14, the minimum supported Pydantic release, the fast suite, the integration
suite, and the release-candidate suite.

The local release gates reported:

- `make check`: 177 passed, 61 deselected, and 7 subtests passed.
- `make check-integration`: 54 passed, 184 deselected, and 22 subtests passed.
- `make check-release`: 232 passed, 6 deselected, and 29 subtests passed.

The documentation contract passed its schema, API, link, math, vocabulary, and
retired-path checks before the tag was created.

## Registry and installed-package gates

[GitHub Actions run `33046468769`](https://github.com/pvd232/viper/actions/runs/33046468769)
built the signed tag, published both files to TestPyPI, compared their hashes,
installed the indexed wheel, and completed the generated-project acceptance
test. The same run then published the files to PyPI through the protected
`pypi` environment.

The first publication attempt preceded the `pvd232/viper` trusted-publisher
entries and stopped at TestPyPI. After those entries were registered, the
failed workflow jobs were rerun. The resulting files match the artifacts from
the original build byte for byte.

An independent clean Python 3.14 environment installed the public PyPI wheel.
It imported every package-root public name, found `py.typed`, returned the CLI
capability document, and completed the generated acquisition, five-stage run,
benchmark confirmation, and terminal verification in 121.27 seconds.

A second clean environment downloaded the public source archive, built its
wheel, installed version 0.1.0a2, imported `viper`, and found `py.typed`.

PyPI and TestPyPI report the filenames, byte counts, and SHA-256 values in the
release-identity table.

## Live NVIDIA L4 gate

The wheel with SHA-256
`f867cfd0b9955d398c69395b435fab8e577d0dc89724f3dab6776d10566635ea`
ran on a `g2-standard-12` Spot VM with an NVIDIA L4. Four live CUDA startup
checks passed in 4.12 seconds. The generated acquisition, five-stage candidate,
benchmark confirmation, and terminal verification passed in 311.15 seconds.

The ephemeral VM and its 500 GB SSD were deleted after the gate. The machine
image `mantra-backup-blueprint` remains available.
