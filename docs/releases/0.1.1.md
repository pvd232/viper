# VIPER 0.1.1

Install the stable distribution:

```bash
python -m pip install viper-provenance==0.1.1
viper --json capabilities
```

The public API imports the GCS provider, so `google-cloud-storage>=3.4,<4` is
now a base dependency. Local runs need no cloud account or credentials.
Existing `[gcs]` installation commands remain supported. MCP remains optional:

```bash
python -m pip install 'viper-provenance[mcp]==0.1.1'
```

This release includes the [complete 0.1.0 candidate feature guide](0.1.0.md):
default verified reuse, default-on journal capture with an opt-out, exact-source
Qwen3 vectors, preserving knowledge refresh, and repaired artifact/checkpoint
examples. The 0.1.0 candidate was uploaded to TestPyPI, not PyPI.

The owner authorized publication without waiting for the full integration suite.
The publication checks the actual default installation and generated-workspace
example on TestPyPI and uploads those same files to PyPI. The
[release receipt](receipts/0.1.1.json) records the completed checks and the
unfinished integration status at publication separately. The temporary workflow
exception has been removed; future releases require successful CI for the exact
tagged commit and publish its retained distributions.
