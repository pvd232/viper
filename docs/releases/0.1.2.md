# VIPER 0.1.2

Install this patch release with:

```bash
python -m pip install --upgrade 'viper-provenance==0.1.2'
```

## Journal publication and semantic search

The default journal encoder limit is 600 seconds for the entire passage batch,
including model download, loading, and CPU inference. Explicit
`[journals].timeout_seconds` settings still override the default. Automatic
capture remains enabled; `enabled = false` disables publication.

The pinned Qwen3-Embedding-0.6B revision, float32 CPU computation, source-text
checks, and immutable run records retain their existing behavior. A publication
retry verifies the saved run and encodes its journal; training stays saved.
See the [complete journal workflow](../how-to/journals.md) for configuration,
recovery, semantic questions, and MCP client timeouts.

The live MCP regression checks three paraphrased questions against distinct
passages, compares retained vector bytes, and exercises review filters and
encoder/runtime separation. Similarity ranks passages; inspect their text and
saved evidence when deciding whether they answer a question.

## Publication checks

The [release workflow](../../.github/workflows/release.yml) requires successful
CI for the exact tagged commit and publishes CI's retained distribution bytes.
TestPyPI installation and generated-project acceptance precede PyPI publication.

Published on October 10, 2026, after all seven required CI jobs passed. The full
integration suite passed 197 tests and 28 subtests. The exact CI-built wheel
passed three CUDA acceptance cases on the designated NVIDIA L4.

The [release receipt](receipts/0.1.2.json) identifies the signed tag, source
commit, CI and publication runs, distribution hashes, clean installations,
rendered documentation checks, and independently captured CUDA reports.
