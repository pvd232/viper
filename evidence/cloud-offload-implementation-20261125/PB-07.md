# CFO-PB-07 verified cleanup

Parent: `c869ea6`.

The existing publication worker runs ready uploads before cleanup. One cleanup
predicate applies current subscriber policy, pending-upload protection, verified
cloud backing, successful whole-workflow completion, closed collection, final
receipts and exact owned-file checks. It never recursively deletes unknown files.

Shared hardlinks tolerate only ctime changes during authorization. Full content
verification and a freshly observed stat are checked again before removal. Replaced
files remain protected. Busy readers trigger a delayed attempt in the same worker.
Stable keep decisions stop polling and become eligible for reconsideration after a
registry/configuration change. A mixed keep/offload operation preserves kept files.
